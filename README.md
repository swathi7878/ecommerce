# 🛒 E-Commerce Web Application

A basic **E-Commerce Web Application** developed as part of the **Thiranex Internship Program**. This project demonstrates the implementation of a full-stack online shopping platform with user authentication, product management, shopping cart functionality, and order tracking using modern web development technologies.

---

## 📌 Project Overview

The application allows users to browse products, manage their shopping cart, place orders, and track previous purchases. It also includes an admin panel for managing products and viewing customer orders.

This project focuses on understanding CRUD operations, REST APIs, authentication, and frontend-backend integration.

---

## ✨ Features

### 👤 User Features

- User Registration

- Checkout Orders

- Responsive User Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/ecommerce-web-application.git
```

### Navigate to the Project

```bash
cd ecommerce
```

### Install Dependencies

```bash
npm install
```

### Start the Server

```bash
npm start
```

### Open in Browser

```
http://localhost:3000
```

## 📖 Application Workflow

1. Register a new account or log in.
2. Browse the available products.
3. Search or filter products by category.
4. Add products to the shopping cart.
5. Update quantities or remove items.
6. Complete the checkout process.
7. View previous orders in the Order Tracking page.
8. Admin users can manage products and monitor customer orders.
